# 🌌 Página do Projeto — Python Lord

Bem-vindo ao **Python Lord**, um jogo arcade feito em **Python com Turtle**.

## 🎮 Sobre o projeto

O objetivo do jogo é controlar o personagem, coletar energias e sobreviver aos inimigos que aparecem automaticamente na arena.

## ✨ Destaques

- Movimentação com teclado
- Sistema de pontuação em tempo real
- Inimigos com movimentação automática
- Progressão de dificuldade por nível
- Sistema de vidas
- Reinício rápido da partida

## 🕹️ Controles

- `↑` / `W` → mover para cima
- `↓` / `S` → mover para baixo
- `←` / `A` → mover para a esquerda
- `→` / `D` → mover para a direita
- `R` → reiniciar o jogo

## ▶️ Como jogar

1. Execute o arquivo principal do projeto.
2. Colete os itens de energia espalhados pela tela.
3. Evite os inimigos para não perder vidas.
4. Continue marcando pontos para avançar de nível.

## 🚀 Execução

```bash
python Python_lord.py
```
